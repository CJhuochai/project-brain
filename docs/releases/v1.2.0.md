# Project Brain v1.2.0

## 中文

这是并发一致性版本。每个工作区现在由一个本机协调者管理：刷新在新快照中完成，成功后原子切换；所有会话始终读取完整、一致的 `snapshot_id`。`stable` 立即返回最近完整快照，`latest` 等待合并后的刷新任务；报告和反馈分别固定快照与规则修订版本。

本版本不上传、修改或构建业务仓库。索引仍只保存在本机。

## English

This release adds concurrency consistency. One local coordinator manages each workspace: refreshes build a new immutable snapshot and switch atomically only after completion. Every request reads one complete, consistent `snapshot_id`. `stable` returns the latest completed snapshot immediately; `latest` waits for the coalesced refresh. Reports and feedback retain their snapshot and rule-revision provenance.

Project Brain still does not upload, modify, or build business repositories. Indexes remain local.
