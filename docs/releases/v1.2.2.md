# Project Brain v1.2.2

## 中文

Codex 插件更新至 0.1.1：用户已明确授权且范围清楚时，完成需求分析后继续实施与验证，不再重复等待方案确认。仅请求分析时保持只读；关键歧义、范围扩大以及项目要求的发布、合并和外部操作审批仍然保留。

本版本无 Go 运行时、协议或数据格式变更，无需迁移。二进制按现有发布流程重新构建。插件用户需同步 `codex-plugin/project-brain-codex` 并重新安装，在新会话中加载技能；仅替换二进制不会更新技能。尚未验证新会话的实际行为改善。

## English

Codex plugin 0.1.1 preserves existing implementation authorization after requirement analysis. Analysis-only requests remain read-only; material ambiguity, expanded scope, and explicit release, merge, or external-action approval requirements remain protected.

No Go runtime, protocol, or data-format changes; no migration is required. Binaries are rebuilt through the existing release workflow. Update and reinstall `codex-plugin/project-brain-codex` and start a new session to load the skill; replacing the binary alone does not update it. Fresh-session behavioral improvement has not yet been verified.
