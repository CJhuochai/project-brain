# Project Brain v2.0.0

## 中文

本版本把代码定位扩展为有证据、有范围、有完整性说明的业务链路分析，继续使用本地 SQLite 和只读业务仓库扫描。

1. 精确符号、驼峰/中文关键词和全文相关性检索，合并去重；需求候选全局排序后应用证据预算。
2. 仓库与文件范围内的稳定符号 ID、方法签名和调用参数数量；同名、同参数数量重载保留歧义。
3. 检索和图查询返回 `coverage`，披露候选/路径/深度截断、循环、未解析关系和解析诊断。
4. `trace_business_flow` / CLI `flow` 展示入口、应用层、服务、仓储、Mapper、表和跨服务阶段及源码位置。
5. `list_contracts` / CLI `contracts` 展示 HTTP、Dubbo 和消息契约；只有明确且唯一的静态契约才能建立跨仓库关系。
6. `get_symbol_context` / CLI `context` 一次读取符号、上下游、链路、契约和风险；默认摘要，可按 ID 展开详情。

### 升级

- **返回格式变化**：`find_business_context` 和 CLI `search` 从证据数组改为 `{ evidence, coverage }`；调用方需更新读取方式。新增字段保留现有证据位置与置信度。
- 协调者协议升级为 2，索引 schema 升级为 9。停止旧 PB 协调者并重启 MCP 客户端；旧协议会明确报错。
- 首次使用在 staging 中重建索引，完成后原子切换；旧快照、历史报告和反馈保留。大工作区超过等待时限时稍后重试，后台任务继续执行。
- v1 快照不能用于 v2 源码查询；省略 `snapshot_id` 自动升级。历史报告继续可读。
- Codex 插件升级为 0.2.0。同步并重新安装插件，在新会话加载工具和技能。

### 能力边界

这是静态分析，不证明运行时可达性。动态路由、服务发现、反射、无法确认的消息发送类型和不明确的契约保持未解析；不会用同名符号猜测跨仓库连线。`coverage.complete` 只描述当前静态索引在查询预算内是否完整。支持的框架形式以解析测试为准；尚未覆盖的动态形式需要直接检查源码。

验证记录见 [v2 验收](../validation/v2.0.0.md)。发布文件覆盖 Windows x64、Linux x64、macOS Intel / Apple Silicon，附 SHA256。

## English

Six upgrades: ranked and deduplicated exact/normalized/full-text search; repository-scoped stable symbol IDs and overload ambiguity; explicit completeness and parser gaps; staged business flows; conservative HTTP/Dubbo/MQ contract links; compact symbol context with detail expansion.

Breaking change: search now returns `{ evidence, coverage }`. Coordinator protocol is 2 and index schema is 9. Stop the old coordinator and restart MCP clients. Indexes rebuild in staging and activate atomically; old snapshots, reports and feedback remain. Retry after a large initial refresh exceeds its wait budget. v1 snapshots cannot serve v2 source queries; saved reports remain readable. Update the Codex plugin to 0.2.0 and start a fresh session.

Completeness refers to indexed static evidence within query limits, not runtime reachability. Dynamic or ambiguous relationships remain unresolved. Four platform binaries include SHA256 checksums. See the linked validation record for executed checks and limitations.
