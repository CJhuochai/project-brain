# Project Brain v1.2.1

## 中文

这是 v1.2.0 的发布验证修复版本。它修正了 Linux 构建机对本地数据目录的测试断言，确保 GitHub Actions 能完成测试、四个平台构建、校验文件生成和 Release 资产上传。

不包含运行功能或数据格式变更；v1.2 的并发一致性功能保持不变。

## English

This is a release-verification fix for v1.2.0. It corrects the local data-directory test on Linux build runners so GitHub Actions can complete testing, four-platform builds, checksum generation, and Release asset upload.

There are no runtime or data-format changes. The v1.2 concurrency-consistency features are unchanged.
